# CreditSafeLogicController

CreditSafe Logic is the automation process that refreshes customer credit and terms data between NetSuite, SQL Server, and Access. It begins by calling two saved searches from NetSuite — one for customer records (JMH-TC-Customer Sync) and one for invoice data (JMH-TC Invoice DSO Sync). The results are downloaded as CSVs, stored under C:\ADSK-Automation\CreditSafe Imports\NetSuiteExports\, and any previous versions are archived in an Old Imports folder. Those CSVs are then imported into SQL tables where they can be joined and validated before Access takes over to process the combined data.

Once the raw data is in place, the automation opens the Access database and runs the query Process Query 09-Import to NetSuite Data, which merges the two datasets and prepares a single output ready for NetSuite. The query’s result is exported to C:\ADSK-Automation\CreditSafe\CreditSafeImport.csv, a clean file that contains all customer and DSO information required for the next import cycle. The process then automatically triggers the NetSuite saved import JMH-Import Terms-Credit Data to load that file back into NetSuite, keeping the system’s credit and payment information current.

Throughout the process, every major step — downloading, importing, Access execution, and re-upload — is written to a timestamped log in C:\ADSK-Automation\Logs\CreditSafeLogic.txt. This provides an easy audit trail for each run and makes troubleshooting straightforward if a file is missing, a column changes, or an Access query fails. In essence, CreditSafe Logic acts as the bridge that keeps NetSuite’s customer credit data synchronized automatically without manual file handling.
